## 0. 一句话

把 §7-3 的 BAI 放进 Haar 小波域：T1 特征按 **LL / HF 分别**用有界门 `α = α_max·σ(a)` 注入
ASL 解码器的 64²/128² 层，注入比 `ρ_band ≡ α`（可解释、每步可记录）。
`α_max = 0` 逐位退化为今天的严格 V=ASL 模型，`α_HF = 0` 逐位退化为被否决的 Band-Limited
Guidance —— **两个原本对立的立场都成了同一个模型族里的特例**，可以在一张 Pareto 图上比较。

---

## 1. 为什么是这个，而不是 BLG

| | Band-Limited Guidance (已否决) | Wavelet-BAI (本设计) |
|---|---|---|
| 立场 | T1 **禁止**进入 detail 子带 | T1 **可以**进入，但有界、可测、可扫 |
| 依据 | 假设泄漏在高频 | 实测泄漏 detail 占比 12.8% < 20% GO 门槛；高频泄漏与错配 T1 边缘相关 +0.032 **低于** null +0.098 |
| 结论 | 移除的东西既不大、也没有解剖形状 ⇒ 空转 | 既然高频里本来没有 T1 结构，**要锐化就得主动把它放进去**——这才是 CNR 增益的唯一来源 |
| 论文价值 | 一个失败的 guard | 一条 performance–fidelity 曲线 + 两个退化特例做锚点 |

2026-08-25 的方向转变（任务是**加速去噪**，允许部分 T1 注入）使 guard 的动机彻底失效，而
BLG 的否决证据反过来成了 BAI 的**动机**：detail 频段是空的，所以它是唯一还没被利用的注入面。

**小波在这里的角色要说清楚**：不是为了省 attention token（那是另一条设计路线，见 §9.2），
BAI 是 O(N) 的逐点门控，本来就不贵。小波提供的是一个**正交、可逆、能量守恒的频带坐标系**，
让"注入了多少高频"变成一个能写进论文的标量，而且这个坐标系与
[leakage_spectrum.py](../scripts/leakage_spectrum.py) 的分析基一致（分析用 sym4，模块内用
haar，见 §2.5）。

## 2. 数学形式

### 2.1 主式

解码器第 s 层（`s ∈ {64², 128²}`），`x_s ∈ R^{B×C×H×W}` 是 up + ASL skip fuse **之后**的特征，
`t_s` 是同尺度的 T1 编码器 skip：

```
m_s               = downsample(1[t1 > 0.05])          脑掩膜, 见 §2.6
u_s               = P_s(t_s) ⊙ m_s                    P_s: 1×1 conv, C_t1 → C
(A_x, D_x)        = DWT_haar(x_s)                     A: LL [B,C,H/2,W/2]; D: [B,C,3,H/2,W/2]
(A_u, D_u)        = DWT_haar(u_s)
A'                = A_x + α_s^LL · N(A_u ; A_x)
D'                = D_x + α_s^HF · N(D_u ; D_x)
x_s'              = IDWT_haar(A', D')

α_s^b = α_max · sigmoid(a_s^b),   a_s^b 初值 −4   (σ(−4)=0.018)
```

`b ∈ {LL, HF}`，HF 三个方向（LH/HL/HH）**共用一个门**——分开成 3 个门只会把证据拆散，
对论文没有可解释性收益（变体见 §9.1）。

### 2.2 RMS 匹配 `N(·;·)` —— 让 α 变成"注入能量占比"

```
N(u ; x) = u · sg[ RMS(x) / RMS(u) ]        sg = stop-gradient, 逐样本逐带
```

**为什么必须有**：实测当前解码器 64² 特征的能量分布是 **LL 76.7% / HF 23.3%**
(‖LL‖/‖x‖ = 0.876, ‖HF‖/‖x‖ = 0.482)。不做 RMS 匹配的话，同一个 α 在 HF 上的实际效果被
LL 压掉一个量级，扫出来的曲线没法解释。做了之后：

```
ρ_s,band := ‖α·N(u)‖_F / ‖x_band‖_F  ≡  α        (实测：α=0.05 → ρ=0.0500，全网格精确相等)
```

即 **α 的数值本身就是"注入了本频带自身能量的百分之多少"**。论文里写
"operating point α=0.1，即 T1 贡献了该频带 10% 的能量"是可以直接说的。

`sg[·]` 让缩放因子不回传：否则模型可以通过缩小 `RMS(u)` 来偷偷放大注入，绕过 α 的界。

### 2.3 `α_max = 0` 必须**短路整个模块**，而不是把 α 设成 0

实测：Haar DWT→IDWT 往返在解码器里逐层做，输出漂移 **1.6e-6**。虽然小，但它会让
"α_max=0 的 ablation baseline" 与现有 checkpoint **不再逐位一致**，破坏"免费 baseline"的价值。

设计要求：`α_max == 0` 时**构造期就不建这个模块**（`self.bai = None`），forward 直接返回 `x`。
实测结果：`torch.equal(y_0, y_baseline) == True`，逐位相同，且 arch 与今天的模型完全一致
⇒ **现有 ckpt 可以直接当 α_max=0 臂的结果用，不需要重训**。

### 2.4 1×1 conv 与 DWT 可交换

`P_s` 是逐像素的通道线性映射，DWT 是逐通道的空间线性算子 ⇒ `DWT(P(t)) = P(DWT(t))`。
所以"先投影后分解"和"先分解后逐带投影"在单投影情形下等价；实现上选前者（DWT 只做一次）。
若要每带独立投影（§9.1 变体）则必须放在 DWT 之后。

### 2.5 为什么模块内用 Haar

| wave | LL 尺寸 (from 64²) | 往返误差 | 备注 |
|---|---|---|---|
| haar | **32²** | 3.0e-7 | 正交、尺寸精确减半，无需裁剪 |
| db2 | 33² | 3.6e-7 | 边界延拓 ⇒ 尺寸不整，要裁 |
| sym4 | 35² | 4.2e-7 | 同上；leakage_spectrum.py 离线分析用它没问题 |

模块内必须尺寸严格对齐（要 IDWT 回原尺度并与 skip 相加），**只有 Haar 干净**。

关于 Haar 高频基是 2×2 分片常数、可能带来块状伪影的担心：在随机特征上实测，
HF-only 注入的能量有 71.4% 落在 >0.75·Nyquist，作为对照的 blur-split（非正交、光滑）是
68.5%；Nyquist 棋盘分量两者分别 0.0154 / 0.0148，**基本没有差别**。
⚠ 但这是在白噪声特征上测的，**不能替代真实训练特征上的检查**——EFC / lapvar / 目视仍然是
§6 的必查项，真出现块状再换 §9.3 的 blur-split 变体。

### 2.6 脑外注入必须掐掉（否则损失函数管不住）

`--premask_asl_inputs` 只掩了 ASL 输入，**T1 是不掩的**（编码器要解剖上下文）。而训练损失也
只在 `t1 > 0.05` 的脑内计算。两者相加的后果：BAI 把 T1 的颅骨/头皮结构注入到细尺度特征后，
**脑外出现结构，损失函数完全不会惩罚它**。

所以 `u_s = P_s(t_s) ⊙ m_s` 里的掩膜不是可选项。`m_s` 由模型内部从 `t1 > 0.05` 算再下采样
（与 runner 在 recon 臂的回退掩膜完全一致，无需新增输入）。
监控项：脑外输出能量 `‖ŷ ⊙ (1−m)‖ / ‖ŷ‖`，见 §6。

### 2.7 参数量

| 组件 | 参数 |
|---|---|
| `P_64`: 1×1 conv 64→64 | 4,096 |
| `P_128`: 1×1 conv 32→32 | 1,024 |
| 4 个门标量 `a_s^b` | 4 |
| **合计** | **≈ 5.1K（占 3.516M 的 0.15%）** |

复杂度表（experiment_plan T5）里这是一个"几乎免费"的模块——这本身就是卖点：
增益或幻觉都不能归因于参数量。

## 3. 接入位置

```
                     ┌──────────────── T1 ConvEncoder2D (共享, 无解码头) ─────────┐
                     │  t1_skips[0] 32@128²   t1_skips[1] 64@64²   ...            │
                     └───────┬────────────────────────┬──────────────────────────┘
                             │ (BAI 新增的第二条梯度通路)                │
 feat_l1 [B,128,32²]         │                        │
 (T1GuidedCoarseHead 输出,   │                        │
  CMF0/CMF1 原样保留)        │                        │
      │                      │                        │
      ▼   ASLDetailDecoder   │                        │
   ┌──────────────────────┐  │                        │
 L2│ up 128→64  @64²      │  │                        │
   │ + asl_skip s1 64@64² │  │                        │
   │ + 1×1 fuse           │  │                        │
   │ ────► x_64 ──────────┼──┴─► WaveletBAI(64ch) ◄───┘  α_64^LL, α_64^HF
   └──────────────────────┘         │
                                    ▼ x_64'
   ┌──────────────────────┐
 L3│ up 64→32   @128²     │
   │ + asl_skip s0 32@128²│
   │ + 1×1 fuse           │
   │ ────► x_128 ─────────┼───► WaveletBAI(32ch) ◄────  α_128^LL, α_128^HF
   └──────────────────────┘         │
                                    ▼ x_128'
                              head 3×3 conv → ŷ
```

尺度/通道对齐（`base_ch=32, depth=4`，两个编码器同构 ⇒ 通道天然一致）：

| 层 | x_s | T1 源 | DWT 后 LL |
|---|---|---|---|
| L2 | `[B,64,64,64]` | `t1_skips[1]` `[B,64,64,64]` | 32² |
| L3 | `[B,32,128,128]` | `t1_skips[0]` `[B,32,128,128]` | 64² |

插入点是**每级 fuse 之后、下一次 up 之前**
（[ASLDetailDecoder.forward](../models/blocks.py#L1120) 的循环体末尾）。

### 3.1 副作用：T1 编码器获得第二条梯度通路（这是好事）

no-seg 臂里 T1 编码器的梯度**只**来自 CMF 的 K 路——CLAUDE.md §7-2 专门列了"T1 可能是惰性的"
这个风险。BAI 的 `P_s` 给了它一条直达重建损失的通路，所以：

- α_max > 0 时，"T1 编码器休眠"这个失败模式基本消失；
- 反过来，如果扫描发现 **α 学着往 0 收敛**（ρ 曲线掉回初值），那就是一个**强得多的阴性结论**：
  不是"T1 没机会起作用"，而是"给了它值通路，N2N 目标仍然不要它"。这个结论对论文比现在的
  T1-zeroed / T1-permuted 对照更有力。

⚠ 反向风险：T1 编码器现在会被优化成"对注入最有用"的样子，也就是可能演化成一个 T1 纹理
发生器。这正是要测的权衡，检测手段见 §6。

## 4. 可测量量

| 量 | 定义 | 用途 |
|---|---|---|
| `ρ_s,band` | `‖α·N(u)‖ / ‖x_band‖`（≡ α） | 论文里"注入了多少"的正式定义；验证 RMS 匹配没坏 |
| `α_s,band` | `α_max·σ(a)` | 学到的门值轨迹；判断是否顶到界 (§6) |
| `Δ_s` | `‖x_s' − x_s‖ / ‖x_s‖` | 该层特征被 T1 改动的总幅度（含 IDWT 混频） |
| `bg_frac` | `‖ŷ⊙(1−m)‖ / ‖ŷ‖` | 脑外泄漏（§2.6 的看门指标） |

**实测：特征级 α → 输出级扰动**（saturated 门、随机输入、未训练投影；用来定扫描网格）

| α | both `Δŷ` | LL-only | HF-only |
|---|---|---|---|
| 0.05 | 3.2% | 2.7% | 1.8% |
| 0.10 | 6.4% | 5.4% | 3.7% |
| 0.20 | 12.6% | 10.6% | 7.4% |
| 0.50 | 30.4% | 25.5% | 18.4% |
| 1.00 | 56.2% | 46.9% | 36.5% |

初始化时（`a=−4, α_max=0.2`）：`α_eff = 0.0036`，输出扰动 **0.23%** ⇒ "开局≈不注入"成立，
模型从今天的解上出发，不会一上来就被 T1 拽走。

读法：**α=1.0 时输出被改动过半，那已经不叫"有界注入"了**——它在扫描里的角色是
"过注入失败锚点"（预期 CNR 高、uMSE 差、泄漏破 null 线），用来把 Pareto 曲线的坏端画出来。
真正的候选工作点在 **0.05 – 0.2**。

## 5. 实验协议

### 5.1 训练臂

| Arm | 配置 | 作用 |
|---|---|---|
| **A0** | `α_max = 0` | 严格 V=ASL。**逐位等于现有模型 ⇒ 复用现有 ckpt，零成本** |
| **A** | `bands=both`, `α_max ∈ {0.05, 0.1, 0.2, 0.5, 1.0}` | 主扫描，5 个新 run |
| **B** | `bands=ll`（α_HF≡0），α_max = A 的最优点 | = Band-Limited Guidance，把被否决的方案做成 ablation |
| **C** | `bands=hf`（α_LL≡0），α_max = A 的最优点 | 隔离"锐化增益是否只来自高频" |

合计 **5 + 2 = 7 个新 run**（~15 h/run；Tianhe 上一批即可）。其余训练配置一律不动
（seed 42、`--best_criterion umse`、EMA 0.9999、loss 权重照旧）。

### 5.2 每个 run 的评测（沿用现有协议，一步不减）

1. 后验选点 `scripts/eval_select_ckpt.py --metric umse`（in-loop best 会被 `best_min_step` 门住）
2. 主指标 uMSE / uPSNR + SSIM；补充 CNR / sCoV / lapvar / EFC / hfen / gmsd
3. **错配 T1**：L1 / SSIM（现基线 0.0285 / 0.931）
4. **泄漏谱** [leakage_spectrum.py](../scripts/leakage_spectrum.py)：detail 能量占比 + 与错配 T1 边缘的相关性（null = +0.098）
5. **E0.3 病灶注入**：4σ GM/WM 病灶保留 + spillover（现基线 0.025–0.027）
6. n-frames sweep 2→8、rCBF ICC
7. ρ / α / bg_frac 的训练轨迹

### 5.3 预注册判据（**先写死，再看数**）

- **有效**：相对 A0，`uMSE 改善 ≥ 3%` **且** 错配 L1 增幅 `≤ 50%`（即 ≤ 0.043）**且**
  泄漏–边缘相关性仍 `< null(+0.098)`。三条全过才叫"注入有收益且没编解剖"。
- **锐化幻觉**（预期会在大 α 出现）：`CNR ↑ ≥ 10%` 同时 `uMSE 变差`。
  → 由 uMSE 仲裁，**不选它做工作点**，但**必须画进 Pareto 图**，这是论文的发现之一。
- **注入无效**：所有 α 的 uMSE 改善 < 1% 且 α 轨迹向 0 收敛 → 结论写成 §3.1 的阴性结论
  （"给了值通路 N2N 仍不要 T1"），BAI 退回 ablation 章节，主臂保持 α_max=0。
- **门顶界**：若最优点的 `σ(a) > 0.9`（α 顶到 α_max），说明界太紧，需要补一个更大的 α_max 点
  再判定，不能直接下结论。

## 6. 失败模式与检测

| 失败模式 | signature | 检测手段 |
|---|---|---|
| T1 纹理发生器（编码器被优化成注入源） | 错配 T1 泄漏暴涨 + 泄漏边缘相关性破 null | §5.2-3/4 |
| 脑外结构（损失管不到） | `bg_frac` 上升 | §4 监控；§2.6 掩膜是预防 |
| Haar 块状伪影 | EFC 恶化 / lapvar 虚高 / 目视棋盘 | §5.2-2 + 目视；退路见 §9.3 |
| α 顶界 | `σ(a)>0.9` | §5.3 最后一条 |
| α 塌到 0 | ρ 轨迹回落到 0.018·α_max | 阴性结论，非 bug |
| 与 skip dropout 的不对称 | 训练期 ASL skip 被 `Dropout2d(0.3)` 丢通道而注入项没有 ⇒ 训练/评测时 T1 相对权重不一致 | 默认对注入项施加**同一个** dropout mask；否则至少记录 train/eval 的 ρ 差 |
| EMA 滞后 | 报告的 ρ 用的是 EMA 权重（验证走 EMA），与 raw 权重的 α 不同 | 两个都记，论文引用 EMA 值 |

## 9. 变体与备选（**先不做**，出问题再取）

1. **每方向独立门**（LH/HL/HH 三个 α）：可解释性下降、证据被拆散。除非目视发现方向性伪影。
2. **低频 addressing 的 cross-attention**（Q/K 取 LL，V=ASL，输出 IDWT 回全带）：解决的是
   attention 的 O(N²) 预算问题（64² 的 4096 token → LL 1024 token，与 CMF1 同价），与 BAI 正交，
   可以叠加。属于另一条设计线，不在本文档范围。
3. **blur-split 替代 Haar**（`x_LF = up(avgpool(x))`, `x_HF = x − x_LF`）：非正交、有冗余，
   但没有块结构。仅当 §6 的块状伪影检查为阳性时启用。
4. **per-channel α**：表达力更强，但 ρ 不再是一个能写进论文的标量。
5. **小波域损失重加权**（按子带 SNR 给 N2N/grad 损失加权）：与本设计完全正交、不动架构，
   针对的是"`psnr_ref` 先升后降 = 噪声模仿"那条已记录的失败模式。可以独立先做。

## 10. 未定项

- **`bands=both` 时 LL/HF 是否共用同一个 `α_max`**：当前设计共用（一个扫描轴）。
  若 A 臂结果显示两带最优 α 差一个量级，再拆成二维网格（成本 ×5）。
- **是否也在 L1(32²) 注入**：现在 32² 已有 CMF1，再叠 BAI 会让"注入"和"注意力引导"的贡献
  纠缠不清。默认**不做**，保持 64/128 是纯注入面、16/32 是纯 addressing 面。
- **投影 `P_s` 是否零初始化**：当前依赖 `a=−4` 的门来实现"开局≈关"（实测 0.23% 扰动，够小）。
  零初始化会让 `P_s` 的梯度在早期极小，反而更难启动。保持普通初始化。
